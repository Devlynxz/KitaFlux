# KitaFlux Brand Assets

**Official name:** KitaFlux  
**Tagline:** Global income. Clear local numbers.

KitaFlux is a modern financial workspace for Filipino freelancers who earn internationally and need accurate local PHP records for invoicing, payments, foreign exchange, fees, income history, and tax-ready reporting.

## Quick use
- `logo/logo-primary.svg`: default website, app header, dashboard.
- `logo/logo-dark.svg`: dark hero/footer/auth backgrounds.
- `logo/logo-light.svg`: white cards or controlled light layouts.
- `logo/logo-monochrome.svg`: invoices, PDFs, print, stamps, one-color contexts.
- `logo/logo-icon.svg`: app icon, sidebar, PWA, compact UI.
- `favicon/favicon.svg` and `favicon/favicon.png`: browser/PWA favicon assets.

Use the SVG files directly whenever possible. Do not rasterize logos for normal UI use.
