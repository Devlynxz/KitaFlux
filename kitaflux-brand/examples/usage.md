# Usage Examples

## React
```jsx
import logo from "./brand/logo/logo-primary.svg";

export function Brand() {
  return <img src={logo} alt="KitaFlux" height={36} />;
}
```

## HTML
```html
<img src="/brand/logo/logo-primary.svg" alt="KitaFlux" width="165">
```

## Dark background
Use `logo-dark.svg`.

## PDF
Use `logo-monochrome.svg` when color reproduction is uncertain or when the invoice is designed for grayscale printing.
