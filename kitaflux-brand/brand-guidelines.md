# KitaFlux Brand Guidelines

## Brand
**Official product name:** KitaFlux  
**Short name:** KitaFlux  
**Tagline:** Global income. Clear local numbers.

### Positioning
A modern financial workspace for Filipino freelancers who earn globally but need clear, accurate local PHP records.

### Brand personality
Professional, modern, trustworthy, financially credible, developer-friendly, clean, efficient, international, and approachable.

## Logo
The symbol represents a simple financial flow: a stable source on the left, movement through conversion, and a highlighted result on the right. It is intentionally abstract rather than using literal `$` and `₱` symbols.

### Minimum size
- Full logo: 140 px wide on screen
- Icon: 24 px in UI; 32 px preferred
- Print/PDF: 25 mm full logo where practical

### Clear space
Keep clear space around the logo equal to approximately the width of the small highlighted dot in the icon.

### Do not
- Stretch or distort the logo
- Change the icon geometry
- Add gradients or shadows directly to the logo
- Place the primary logo on low-contrast backgrounds
- Recolor individual logo elements outside approved variants

## Typography
- **Primary UI:** Inter
- **Headings:** Inter 600–750
- **Body:** Inter 400–500
- **Buttons:** Inter 600
- **Financial values:** JetBrains Mono 500–600 when alignment and numeric comparison matter
- **Tables:** Inter for labels; JetBrains Mono for currency columns
- **Invoices/PDFs:** Inter for the main document, with tabular figures enabled where supported

## UI direction
Use generous spacing, restrained borders, clear hierarchy, and financial values that are easy to scan.

- Dashboard: quiet surfaces with strong numeric hierarchy
- Sidebar: compact and neutral; primary only for active state
- Buttons: primary blue for the main action; avoid multiple competing accents
- Forms: clear labels, useful validation, visible currency context
- Invoices: document-first, monochrome-friendly, minimal decoration
- Tables: aligned currency columns and explicit statuses
- Financial cards: emphasize received PHP, conversion rate, and net proceeds
- Charts: use semantic color meaning consistently
- Empty states: calm, practical, and action-oriented
- Auth: simple, credible, product-focused
- PDFs: prioritize readability and print safety over decorative UI
